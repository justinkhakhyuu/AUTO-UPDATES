READ THIS FIRST
================

On GitHub website you only need ONE file for the loader:

  updates/manifest.json

Open that file → change "version": "1.0.0" to "1.0.2" → save/commit.

The loader compares that number to:
  internal/brutal/version.json  (on your PC, inside the loader folder)

If GitHub version is higher → updater runs.


WHERE DO DLL FILES GO?
======================

NOT in the numbered folders on this repo.

DLL files go here on GitHub website:

  Top menu: Releases  (NOT "Code" folder)
  → Create new release
  → Tag name: brutal-1.0.2
  → Upload: Client.dll (+ libTERMINALX999Cheats.so for brutal)

Direct link:
  https://github.com/justinkhakhyuu/AUTO-UPDATES/releases


ON YOUR PC (local only — not on GitHub):
  d:\FREE FIRE PROJECTS\DEV\AUTO-UPDATES\release-assets\brutal-1.0.2\
  Drop DLLs there before uploading to Releases.


QUICK VERSION TEST (no DLLs needed to SEE detection):
  1. manifest.json version → 1.0.2
  2. Loader already has local version 1.0.0
  3. Click CHECK FOR UPDATES
  4. It will TRY to update (download may fail until you upload real DLLs to Releases)
