BRUTAL RELEASE — tag: brutal-1.0.0
==================================

Put these 2 files in THIS folder (same names):

  1) Client.dll
  2) libTERMINALX999Cheats.so

Then upload BOTH to GitHub:
  Repo → Releases → brutal-1.0.0 → Edit → attach/replace assets

Asset names on GitHub MUST be exactly:
  Client.dll
  libTERMINALX999Cheats.so

After upload, run from repo root:
  powershell -File Scripts\Update-ManifestHashes.ps1 -Channel brutal -Version 1.0.0

That updates updates\manifest.json with real sha256 + size.
Commit manifest.json to main.

Loader saves downloaded files to:
  internal\brutal\Client.dll
  internal\brutal\Libraries\libTERMINALX999Cheats.so
